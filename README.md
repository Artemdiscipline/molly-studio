# Molly studio — сайт-визитка

Одностраничный сайт студии ногтевого сервиса Molly studio (Липецк,
Политехническая улица, 1). Чистые HTML и CSS, без сборщиков и библиотек;
снаружи грузятся только шрифты Google Fonts (Jost и Manrope); живая
карта OpenStreetMap подгружается, только если посетитель нажмёт на неё.

Запись идёт только через YClients: все кнопки «Записаться» ведут на
https://n1778538.yclients.ru/ в новой вкладке. Своей формы записи на сайте
нет и быть не должно, иначе у студии разъедется расписание.

## Как открыть

- Быстро: двойной клик по `index.html`.
- Как на хостинге: в папке проекта выполнить
  `python -m http.server 8000` и открыть http://localhost:8000.
- Опубликован на GitHub Pages: https://artemdiscipline.github.io/molly-studio/
  (репозиторий https://github.com/Artemdiscipline/molly-studio, ветка
  `main`, корень). Любой `git push` в `main` обновляет сайт за 1–2 минуты.
- Переезд на другой хостинг или свой домен — см. пункт «Свой домен» в `TODO.md`.

## Как заменить фото работ

1. Подготовить два файла на каждую работу:
   - квадратное превью 480×480, JPEG качество ~75 %, до ~50 КБ;
   - крупное фото, длинная сторона до 1080 px, JPEG ~75 %, до ~150 КБ.
   Сжать можно в https://squoosh.app или любом редакторе.
2. Положить в `assets/works/` под теми же именами (`work-05-sq.jpg` и
   `work-05.jpg`) — тогда HTML трогать не нужно.
3. Если меняется сюжет фото, поправить `alt` у соответствующего `<img>`
   в блоке `#works`: он же выводится подписью при просмотре.
4. Добавить 13-е фото: скопировать строку `<li>…</li>` в `#works` и
   поменять номера. Сетка — 3 колонки на телефоне и 4 на компьютере,
   поэтому лучше держать 12 фото.

Фото в шапке — `assets/hero-560.jpg` (ширина 560) и `assets/hero-880.jpg`
(ширина 880), пропорции 4:5.

## Как поменять цены и услуги

Всё в `index.html`, блок `<section id="prices">`. Одна строка прайса:

```html
<li><span class="name">Японский маникюр</span><span class="time">1 ч 30 мин</span><span class="price">1 500 ₽</span></li>
```

- `time` можно не писать — строка останется ровной.
- Добавили или убрали услугу — поправьте счётчик в заголовке группы
  (`<span class="price-group__meta">6 услуг</span>`).
- Между тысячами ставьте обычный пробел: `1 500 ₽`.
- Поменяйте дату в строке «По данным онлайн-записи на …».
- Источник правды — YClients: сначала правим там, потом на сайте.

Группы стоят в двух колонках: слева «Маникюр» и «Наращивание»,
справа «Педикюр» и «Дизайн». На телефоне группы сворачиваются
(открыта только «Маникюр»), порядок задают классы
`price-group--1` … `price-group--5`.

## Отзывы

В секции `#reviews` — две плашки рейтинга (2ГИС и Яндекс Карты) и три
отзыва с Яндекс Карт. Одна карточка:

```html
<li>
  <figure class="review">
    <blockquote cite="ССЫЛКА НА ОТЗЫВЫ">Цитата — цельная фраза с начала предложения</blockquote>
    <figcaption>
      <cite>Имя Ф.</cite>
      <span class="meta">Яндекс Карты · месяц год</span>
    </figcaption>
  </figure>
</li>
```

Кавычки «» подставляются стилями. Цитату не переписывать: можно только
обрезать конец. Звёзды, если оценка известна, — `<span class="stars"
aria-label="5 из 5">★★★★★</span>` в начале `.meta`.

## Блок «О студии»

Стоит между «Работы» и «Услуги и цены»: текст слева, два фото интерьера
справа (`assets/about/`, 600×800). Текст — в `<p class="about__lead">`.

Мастера: список `<ul class="masters">` скрыт атрибутом `hidden`, внутри —
закомментированный шаблон карточки. Чтобы показать: раскомментировать
`<li class="master">` для каждого мастера, положить фото в
`assets/masters/` (квадрат от 600×600) и убрать `hidden` у списка.

Скрыть весь блок: добавить класс `is-draft` к `<section id="about">`.

## Как перекрасить сайт

В начале `style.css`:

```css
:root {
  --paper: #f6f3f7;   /* фон — сиреневые стены студии */
  --ink: #141214;     /* текст и тёмные блоки — чёрный из логотипа */
  --accent: #fc8ca6;  /* кнопки и акценты — розовый с обложки ВК */
}
```

Остальные цвета (линии, приглушённый текст, тёмный розовый для ссылок)
вычисляются из этих трёх через `color-mix()`, их менять не нужно.
Кнопки пишутся цветом `--ink` по `--accent`, поэтому акцент должен
оставаться светлым. Шрифты задаются в `--font-display` и `--font-body`
и в ссылке на Google Fonts в `<head>`.

## Карта

На странице стоит картинка `assets/map.jpg` с кнопкой «Открыть
интерактивную карту»: по нажатию она заменяется живой картой
OpenStreetMap (адрес в атрибуте `data-embed`). Так страница не грузит
тяжёлый виджет заранее и не «залипает» при прокрутке колёсиком над картой.
Точка — 52.604821, 39.5097 из карточки 2ГИС. Чтобы открывались Яндекс
Карты, замените `data-embed` у `#map-frame` на:

```
https://yandex.ru/map-widget/v1/?ll=39.509700%2C52.604821&z=16&pt=39.509700%2C52.604821%2Cpm2rdm
```

## Скорость

- Шрифты подключены без блокировки отрисовки: пока они грузятся,
  текст виден системным шрифтом.
- Фото работ и карта грузятся лениво (`loading="lazy"`), в шапке —
  одно фото подходящего размера из `srcset`.
- Окно просмотра фото создаётся скриптом при первом нажатии — до этого
  в разметке нет ни счётчика, ни пустой картинки. Сразу показывается уже
  загруженное превью, крупное подменяется по готовности; соседние фото
  подгружаются заранее.
- Без эффектов размытия и плавной прокрутки — на слабых телефонах
  именно они дают подтормаживание.
